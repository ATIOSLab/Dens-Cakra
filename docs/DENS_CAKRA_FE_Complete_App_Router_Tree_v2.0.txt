RULES
- `page.tsx` creates a UI route.
- `[id]` folders create dynamic route segments.
- `_components`, `_lib`, `_schemas`, `_actions` are private/non-routable folders.
- `loading.tsx`, `error.tsx`, and `not-found.tsx` belong at meaningful boundaries.
